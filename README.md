## Why Markdown?

- **Instantly searchable** across the entire Bible
- **Works offline** with AI assistants
- **Easy to embed** in study tools, curriculum, and presentations
- **Human-readable** source — no app or API needed
- **Standard format** — works with any text editor or AI platform

## How to Use

Place any translation folder in your agent's workspace:

```
~/.openclaw/workspace/bibles/English/bsb/bsb.md
```

Then ask your assistant questions like:
- "What does BSB say about faith?"
- "Read Genesis 1:1-5 from BSB"
- "Find all verses about grace"
- "Compare ESV and KJV for Romans 8:28"

## Format

All translations use consistent Markdown formatting:
- `# Book Name` for book headers
- `## Chapter N` for chapter headers
- `**vN**` for verse markers

## Verification

All translations have been verified with automated audit scripts checking:
